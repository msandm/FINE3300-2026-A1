# FINE3300 – Assignment 1: Currency Exchange Converter

## Overview
This project is a Python program that converts money between US dollars (USD) and Canadian dollars (CAD) using exchange rates read from a data file. The assignment has three parts: building my own currency converter, having an AI model build the same converter independently, and comparing the two solutions.

## Course Information
**Course:** FINE3300

**Assignment:** A1
**Author:** Moosa Nadeem

## Part 1 – Currency Converter Class
In Part 1, I will design a Python class, that reads exchange rate data from `[BankOfCanadaExchangeRate.2026.csv]` and converts amounts between USD and CAD.

The class includes a method, `[convert]`, that takes three inputs:
1. **Amount** – the amount of money to convert
2. **From currency** – the starting currency (`USD` or `CAD`)
3. **To currency** – the target currency (`USD` or `CAD`)


## Part 2 – AI-Generated Solution
In Part 2, I will give the same task to an AI model without sharing my own code. I will refine my prompts until the model produced a program with the correct output.

## Part 3 – Comparison of My Code and the AI's Code
In Part 3, I compare the code that I created with the code that the AI model generated and write a paragraph comparing the code and stating the exact model that I used along with the prompts that I provided.
